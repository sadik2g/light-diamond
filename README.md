# Light Diamond

A dynamic web application and digital platform built with PHP, featuring an integrated administration panel, custom database management utilities, responsive styling, and a structured layout for portfolio items, services, and blog posts.

## 🚀 About the Project

Light Diamond is a full-featured web solution designed to showcase business or portfolio offerings while offering a powerful administrative dashboard. It provides backend management for posts, comments, categories, and user profiles, paired with a clean, responsive front-end interface built on modern Bootstrap and CSS architecture.

## 🛠️ Built With

* **PHP** - Dynamic server-side scripting and business logic.
* **MySQL** - Relational database structure for content and user data management.
* **Bootstrap** - Responsive front-end framework for mobile-first layouts.
* **Font Awesome & Custom CSS** - Scalable vector icons and custom styling elements.
* **JavaScript & jQuery** - Interactive front-end scripts and asynchronous admin workflows.

## ⚙️ Getting Started Locally

Follow these instructions to set up and run the application on your local development environment (such as XAMPP):

1. **Clone the repository:**
```bash
git clone https://github.com/sadik2g/light-diamond.git

```


2. **Move files to your local server:**
* Place the cloned project folder directly into your local server directory (e.g., `C:\xampp\htdocs\Light Diamond`).


3. **Start your local server:**
* Open XAMPP Control Panel and start both **Apache** and **MySQL**.


4. **Configure the Database:**
* Navigate to `http://localhost/phpmyadmin` in your web browser.
* Create a new database for the application.
* Import any associated database dump or configure your PHP connection scripts to hook up your local database credentials.


5. **Access the application:**
* Open your browser and go to `http://localhost/Light-Diamond/` to view the project live.
